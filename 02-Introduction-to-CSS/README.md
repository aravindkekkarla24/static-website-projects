# Introduction to CSS

This is my second project, created to learn the basics of CSS and how CSS can be connected to HTML to style a webpage.

## About

In this project, I created a simple tourism webpage and applied CSS styling to the HTML elements.

## Technologies Used

* HTML
* CSS

## Concepts Learned

### HTML

* `div` – A container element used to group HTML elements
* `class` attribute – Used to assign a class name to an HTML element

### CSS

* CSS Ruleset
* Selector
* Property
* Value
* `text-align`
* `color`

## Project

The webpage contains:

* Tourism heading
* Travel description
* Get Started button
* Center-aligned content
* Blue heading

## Learning Goal

The goal of this project is to understand how CSS is connected to HTML and how CSS selectors, properties, and values are used to style HTML elements.
