# Introduction to HTML

This is my first HTML program, created to learn the basic structure and elements of HTML.

## About

In this project, I created a simple tourism webpage using basic HTML elements.

## Technology Used

* HTML

## HTML Elements Used

* `<!DOCTYPE html>` – Defines the HTML document type
* `<html>` – Root element of the webpage
* `<head>` – Contains information about the webpage
* `<title>` – Defines the webpage title
* `<body>` – Contains the visible webpage content
* `<h1>` – Creates a main heading
* `<p>` – Creates a paragraph
* `<button>` – Creates a button

## Project

The webpage contains:

* Tourism heading
* A short travel description
* Get Started button

## Learning Goal

The goal of this project is to understand the basic structure of an HTML document and learn how HTML elements are used to create a webpage.
