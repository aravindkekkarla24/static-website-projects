# Tourism Static Web Page

This is a Bootstrap practice project created to learn and apply **Bootstrap Flexbox utility classes, CSS properties, and section navigation** to create a simple tourism webpage.

## Live Demo

**Live Demo** → https://tourstaticpag.ccbp.tech/

## About

In this project, I created a simple tourism webpage with a home section and a tourist places section. The webpage includes a tourism background, introduction content, and cards for popular tourist destinations such as the Taj Mahal, Varanasi, Goa, and Manali.

The project also uses the CCBP UI Kit to navigate between the home section and tourist places section using the **Get Started** and **Back** buttons.

## Technology Used

* HTML

* CSS

* Bootstrap

* CCBP UI Kit

## Bootstrap Classes Used

* `d-flex` – Creates a Flexbox container

* `flex-column` – Arranges elements vertically

* `flex-row` – Arranges elements horizontally

* `justify-content-end` – Aligns content toward the end of the main axis

* `justify-content-around` – Adds equal space around flex items

* `align-items-center` – Aligns items at the center of the cross axis

* `btn` – Applies Bootstrap button styling

* `btn-info` – Applies Bootstrap info button styling

## CSS Properties Used

* `height` – Sets the height of elements

* `width` – Sets the width of elements

* `background-image` – Adds background images

* `background-size` – Controls the size of background images

* `background-color` – Sets the background color

* `padding` – Adds space inside elements

* `margin` – Adds space outside elements

* `border` – Adds borders around elements

* `border-radius` – Creates rounded corners

* `text-align` – Aligns text

* `font-family` – Defines the font

* `font-size` – Sets the text size

* `font-weight` – Controls the thickness of text

* `font-style` – Changes the text style

* `letter-spacing` – Controls the spacing between characters

* `word-spacing` – Controls the spacing between words

* `object-fit` – Controls how images fit inside their containers

## Project

The webpage contains:

* A tourism home section

* A tourism background image

* A Tourism heading

* A tourism description

* A Get Started button

* A tourist places section

* Taj Mahal tourist place card

* Varanasi tourist place card

* Goa tourist place card

* Manali tourist place card

* Tourist place images and descriptions

* Know More buttons

* A Back button

* Navigation between sections using the CCBP UI Kit `display()` function

## Learning Goal

The goal of this project is to understand how **Bootstrap Flexbox utilities, CSS properties, and section navigation** can be combined to create a simple static tourism webpage with multiple sections and interactive navigation.
