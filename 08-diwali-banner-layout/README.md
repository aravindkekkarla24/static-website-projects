# Diwali Banner Layout

This is a Bootstrap practice project created to learn and apply **Bootstrap Flexbox utility classes** and CSS properties to design a simple Diwali banner and shopping layout.

## Live Demo

**Live Demo** → https://diwalibannerrs.ccbp.tech/

## About

In this project, I created a Diwali-themed banner with a background image, heading, product cards, product images, prices, and a **View More** button. Bootstrap Flexbox utility classes are used to arrange the product cards horizontally.

## Technology Used

* HTML

* CSS

* Bootstrap

## Bootstrap Classes Used

* `d-flex` – Creates a flex container

* `flex-row` – Arranges flex items horizontally

* `justify-content-center` – Centers the flex items along the main axis

* `btn` – Applies Bootstrap button styling

* `btn-primary` – Applies Bootstrap primary button styling

## CSS Properties Used

* `height` – Sets the height of the banner

* `background-image` – Adds the Diwali background image

* `background-size` – Controls the background image size

* `color` – Sets the text color

* `font-family` – Defines the font

* `font-size` – Sets the text size

* `font-weight` – Controls the thickness of text

* `width` – Sets the width of elements

* `padding` – Adds space inside elements

* `margin` – Adds space outside elements

* `background-color` – Sets the background color

* `border-radius` – Creates rounded corners

* `text-align` – Aligns text within elements

## Project

The webpage contains:

* A Diwali banner section

* A Diwali-themed heading

* A product section

* Diwali Air Balloon card

* Diwali Lamp card

* Sparklers card

* Fire Cracker card

* Product images and prices

* A View More button

* Bootstrap Flexbox layout for arranging product cards

## Learning Goal

The goal of this project is to understand how **Bootstrap Flexbox utility classes** and **CSS properties** can be combined to create attractive and organized webpage layouts.
