# Bootstrap Flexbox Layout Practice

This is a Bootstrap practice project created to learn and apply Flexbox layout concepts using Bootstrap utility classes.

## Live Demo

**Live Demo** → https://chatspagee.ccbp.tech

## About

In this project, I created a simple chat page between two persons and styled the chat interface using CSS properties and Bootstrap Flexbox concepts.

## Technology Used

* HTML
* CSS
* Bootstrap

## CSS Properties Used

* `height` – Sets the height of elements
* `background-color` – Sets the background color
* `background-image` – Adds a background image
* `color` – Sets the text color
* `text-align` – Aligns the text
* `font-family` – Defines the font
* `font-size` – Sets the text size
* `font-weight` – Controls the thickness of text
* `padding` – Adds space inside elements
* `margin` – Adds space outside elements
* `border-radius` – Creates rounded corners

## Project

The webpage contains:

* A chat page background
* A person name section
* Sent messages
* Received messages
* Different background colors for sent and received messages
* Rounded message boxes
* Styled chat messages

## Learning Goal

The goal of this project is to understand how Bootstrap Flexbox and CSS properties can be used to create and style a simple chat page layout.
