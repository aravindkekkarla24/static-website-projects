# Taj Mahal Carousel - Practice Project

## Live Demo

https://carosaltaj.ccbp.tech/

## About This Project

This project was created while learning **HTML, CSS, and Bootstrap concepts**. It demonstrates how to use the **Bootstrap Carousel component** to display multiple images in a sliding format.

The webpage displays images of the **Taj Mahal** along with a short description section below the carousel.

## What I Learned

* Using Bootstrap CDN in a project
* Creating an image slider with Bootstrap Carousel
* Using Bootstrap classes for layout and styling
* Structuring a basic HTML webpage
* Applying CSS for styling

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* jQuery
* Popper.js

## Project Features

* Image slider using Bootstrap Carousel
* Responsive layout
* Taj Mahal information section
* Navigation controls (Previous and Next buttons)
