# CSS Text Properties

This is a CSS practice project created to learn and apply different CSS text and font properties.

## About

In this project, I created a simple webpage about front-end web development and styled the heading and paragraph using various CSS text properties.

## Technology Used

* HTML
* CSS

## CSS Properties Used

* `color` – Sets the color of the text
* `text-transform` – Changes the capitalization of text
* `font-family` – Defines the font used for the text
* `font-style` – Specifies the style of the font
* `font-weight` – Controls the thickness of the text
* `text-shadow` – Adds a shadow effect to text
* `text-align` – Aligns the text
* `letter-spacing` – Controls the space between letters
* `word-spacing` – Controls the space between words
* `text-decoration` – Adds decoration to text
* `text-decoration-style` – Defines the style of the text decoration
* `text-decoration-color` – Sets the color of the text decoration
* `text-indent` – Indents the first line of a paragraph
* `line-height` – Controls the space between lines of text

## Project

The webpage contains:

* A front-end web development heading
* A paragraph describing front-end web development
* Different CSS text properties applied to the heading
* Different CSS text properties applied to the paragraph

## Learning Goal

The goal of this project is to understand how CSS text and font properties are used to style, align, decorate, and improve the readability of text on a webpage.
