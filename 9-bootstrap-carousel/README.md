# Bootstrap Carousel

This is a Bootstrap practice project created to learn and apply **Bootstrap Carousel components** along with CSS properties to create an image slideshow.

## Live Demo

**Live Demo** → https://carouselses.ccbp.tech/

## About

In this project, I created a simple Taj Mahal tourism webpage using a **Bootstrap Carousel**. The carousel contains multiple Taj Mahal images with navigation indicators and previous/next controls. A heading and descriptive paragraph are displayed below the carousel.

## Technology Used

* HTML

* CSS

* Bootstrap

## Bootstrap Classes and Components Used

* `carousel` – Creates a Bootstrap carousel

* `carousel slide` – Adds the sliding effect to the carousel

* `carousel-indicators` – Displays indicators for navigating between slides

* `carousel-inner` – Contains all carousel slides

* `carousel-item` – Defines an individual carousel slide

* `active` – Sets the first carousel slide as active

* `carousel-control-prev` – Creates the previous slide button

* `carousel-control-next` – Creates the next slide button

* `carousel-control-prev-icon` – Displays the previous navigation icon

* `carousel-control-next-icon` – Displays the next navigation icon

* `d-block` – Displays the image as a block element

* `w-100` – Sets the image width to 100%

* `visually-hidden` – Hides text visually while keeping it accessible to screen readers

## CSS Properties Used

* `height` – Sets the height of the carousel images and background container

* `width` – Controls the width of elements

* `background-image` – Adds a background image

* `background-size` – Controls the size of the background image

* `padding` – Adds space inside elements

* `border` – Adds a border around the card

* `border-radius` – Creates rounded corners

* `background-color` – Sets the background color

* `object-fit` – Controls how images fit inside their containers

* `font-family` – Defines the font

* `text-align` – Aligns the heading

* `color` – Sets the text color

## Project

The webpage contains:

* A dark blue background section

* A styled content card

* A Bootstrap image carousel

* Three Taj Mahal images

* Carousel indicators

* Previous and next navigation controls

* A Taj Mahal heading

* A descriptive paragraph about the Taj Mahal

## Learning Goal

The goal of this project is to understand how the **Bootstrap Carousel component** works and how carousel indicators, slides, and navigation controls can be combined with CSS to create an interactive image slideshow.
