# CSS Box Properties

This is a CSS practice project created to learn and apply different CSS box properties.

## Live Demo

**Live Demo** → https://cssboxpro.ccbp.tech

## About

In this project, I created a simple webpage using a container and applied different CSS box properties to understand how spacing, borders, dimensions, and backgrounds work.

## Technology Used

* HTML
* CSS

## CSS Box Properties Used

* `background-color` – Sets the background color of the element
* `height` – Sets the height of the element
* `border-color` – Sets the color of the border
* `border-width` – Sets the thickness of the border
* `border-style` – Defines the style of the border
* `border-radius` – Rounds the corners of the element
* `margin-top` – Adds space outside the top of the element
* `margin-right` – Adds space outside the right of the element
* `margin-bottom` – Adds space outside the bottom of the element
* `margin-left` – Adds space outside the left of the element
* `padding-top` – Adds space inside the top of the element
* `padding-left` – Adds space inside the left of the element

## Project

The webpage contains:

* A blue container
* A bordered container with rounded corners
* Spacing using margin properties
* Internal spacing using padding properties
* A heading displaying the word "Content"

## Learning Goal

The goal of this project is to understand how CSS box properties are used to control the size, border, spacing, and overall layout of elements on a webpage.
