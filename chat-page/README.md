# Chat Page UI

This is a simple Chat Page user interface built using HTML and CSS.  
The page shows a conversation between two people using styled message bubbles.

## Live Demo
🔗 https://chatpagestaticc.ccbp.tech/

## Technologies Used
- HTML
- CSS


## Features
- Chat interface design
- Sent and received message bubbles
- Background image for chat screen
- Header section showing the person's name
- Different styles for sent and received messages

## What I Learned
- Creating a basic HTML page structure
- Connecting and applying CSS styles
- Using background images in CSS
- Styling text using font properties
- Using padding and margins for spacing
- Creating chat message bubbles using border-radius
- Aligning text using text-align property

## Project Purpose
The purpose of this project is to practice building a simple chat interface using HTML and CSS.  
While building this project, I applied concepts such as page layout, background images, text styling, padding, margins, and border-radius to design message bubbles similar to a real chat application.
