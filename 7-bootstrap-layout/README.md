# Design Layouts Using Bootstrap

This is a Bootstrap practice project created to learn and apply **Bootstrap utility classes** and CSS properties for designing a simple tourism webpage.

## Live Demo

**Live Demo** → https://bootstrapout.ccbp.tech/

## About

In this project, I created a simple tourism landing page with a background image, a tourism card, heading, description, and a **Get Started** button. Bootstrap utility classes are used to control the layout, text colors, and button styling.

## Technology Used

* HTML

* CSS

* Bootstrap

## Bootstrap Classes Used

* `d-flex` – Makes an element a flex container

* `flex-column` – Arranges flex items vertically

* `justify-content-end` – Aligns the content at the end of the main axis

* `text-warning` – Applies Bootstrap warning text color

* `text-light` – Applies a light text color

* `btn` – Applies Bootstrap button styling

* `btn-danger` – Applies Bootstrap danger button styling

## CSS Properties Used

* `height` – Sets the height of elements

* `background-image` – Adds a background image

* `background-size` – Controls the size of the background image

* `background-color` – Sets the background color

* `margin` – Adds space outside elements

* `padding-top` – Adds space inside the top of an element

* `text-align` – Aligns the text

* `border-radius` – Creates rounded corners

* `font-family` – Defines the font

* `letter-spacing` – Controls the space between characters

* `word-spacing` – Controls the space between words

## Project

The webpage contains:

* A tourism background image

* A tourism information card

* A Tourism heading

* A short tourism description

* A Get Started button

* Bootstrap Flexbox utilities for positioning the card

* Bootstrap text and button utility classes

## Learning Goal

The goal of this project is to understand how **Bootstrap utility classes** and **CSS properties** can be combined to create a simple, responsive, and visually appealing webpage layout.
