# Goa Tourism Page

This is a Bootstrap practice project created to learn and apply **Bootstrap Carousel, Flexbox utility classes, and embedded YouTube videos** to create a tourism webpage about Goa.

## Live Demo

**Live Demo** → https://goapagees.ccbp.tech/

## About

In this project, I created a Goa tourism webpage with a Bootstrap image carousel, a description about Goa, and three embedded YouTube videos. Bootstrap classes are used to create the carousel, arrange the video sections, and make the webpage layout more organized.

## Technology Used

* HTML

* CSS

* Bootstrap

* YouTube Embed

## Bootstrap Classes and Components Used

* `carousel` – Creates an image carousel

* `carousel slide` – Adds the sliding effect to the carousel

* `carousel-indicators` – Provides indicators for the carousel slides

* `carousel-inner` – Contains the carousel slides

* `carousel-item` – Defines each carousel slide

* `active` – Makes the first carousel item active

* `carousel-control-prev` – Creates the previous slide control

* `carousel-control-next` – Creates the next slide control

* `carousel-control-prev-icon` – Displays the previous navigation icon

* `carousel-control-next-icon` – Displays the next navigation icon

* `d-block` – Makes the image a block-level element

* `w-100` – Sets the width to 100%

* `d-flex` – Creates a Flexbox container

* `flex-row` – Arranges elements horizontally

* `justify-content-around` – Adds equal space around flex items

* `embed-responsive` – Creates a responsive embedded content container

* `embed-responsive-16by9` – Provides a 16:9 aspect ratio for embedded videos

## CSS Properties Used

* `height` – Sets the height of elements

* `width` – Sets the width of elements

* `background-color` – Sets the background color

* `padding` – Adds space inside elements

* `border` – Adds a border around the card

* `border-radius` – Creates rounded corners

* `display` – Defines the layout behavior of elements

* `flex-direction` – Defines the direction of flex items

* `text-align` – Aligns text

* `font-family` – Defines the font

## Project

The webpage contains:

* A Goa tourism background section

* A main content card

* A Bootstrap image carousel

* Three Goa-related images

* Carousel indicators and navigation controls

* A Goa description section

* Three embedded YouTube videos

* A Flexbox layout for arranging the videos horizontally

## Learning Goal

The goal of this project is to understand how **Bootstrap Carousel, Flexbox utilities, responsive embedded videos, and CSS properties** can be combined to create an interactive and informative tourism webpage.
