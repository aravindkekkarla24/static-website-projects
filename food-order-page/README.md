# Food Order Page

This is a simple Food Order landing page created using HTML, CSS, Bootstrap, and Google Fonts.  
The page shows a food background image with a card section that contains a title, description, and a button.

## Live Demo
🔗 https://foodorderstati.ccbp.tech/

## Technologies Used
- HTML
- CSS
- Bootstrap
- Google Fonts

## Google Fonts Used
- Bree Serif
- Roboto

## Features
- Full screen background image
- Card section aligned at the bottom of the page
- Styled heading and description
- "Book Now" button
- Layout using Bootstrap flex utilities

## What I Learned
- Basic HTML page structure
- Connecting CSS with HTML
- Using Bootstrap CDN in HTML
- Using Flexbox utilities (`d-flex`, `flex-column`, `justify-content-end`)
- Applying background images using CSS
- Styling text using Google Fonts
- Creating card layouts using padding and border radius
- Button styling

## Project Purpose
The purpose of this project is to practice building a simple landing page layout using HTML, CSS, Bootstrap, and Google Fonts.  
While building this project, I applied concepts such as background images, flexbox layout, typography, card styling, and button design to create a clean user interface.
