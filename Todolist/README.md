# Todo List Web Page

This is a simple Todo List web page created using HTML and CSS.  
I built this project while practicing basic web development concepts.

## Live Demo
🔗 https://statictodopage.ccbp.tech/

## Technologies Used
- HTML
- CSS


## Features
- Background image
- Todo title and description
- Start button
- Simple and clean UI design

## What I Learned
- Basic HTML structure
- Connecting CSS with HTML
- Using background images in CSS
- Styling text using font properties
- Button styling and alignment
- Text alignment and layout

## Project Purpose
The purpose of this project is to practice and understand fundamental HTML and CSS concepts.  
While building this webpage, I applied concepts like HTML page structure, CSS selectors, text styling, background images, button styling, and layout alignment.  
This project helped me improve my understanding of how HTML and CSS work together to create a simple user interface.
