# Profile Webpage with Hyperlinks

## Project Description

This project is a simple profile webpage created using **HTML and Bootstrap** while learning hyperlink concepts. The page displays a profile section, awards list, and a biography section.

The project also demonstrates how **internal and external hyperlinks** work in a webpage.


## Live Demo:

https://hyperlinksss.ccbp.tech/


## Features

* Profile section with image and description
* Awards section with a list of achievements
* Internal hyperlink navigation to the Bio section
* External hyperlink to the Vincent Club Wikipedia page
* Basic layout using Bootstrap

## Concepts Practiced

* HTML page structure
* Hyperlinks using the `<a>` tag
* Internal page navigation using **id attributes**
* External links using `target="_blank"`
* Basic Bootstrap integration using CDN

## Technologies Used

* HTML


## Live Link Example

Internal Link Example:
`<a href="#bioSection">Bio</a>`

External Link Example:
`<a href="https://en.wikipedia.org/wiki/Vincent%27s_Club" target="_blank">Vincent Club</a>`
