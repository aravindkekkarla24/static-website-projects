# Flexbox Layouts Practice

This is a CSS practice project created to learn and apply **Flexbox layout concepts** using CSS Flexbox properties.

## Live Demo

**Live Demo** → https://flexboxlayotss.ccbp.tech

## About

In this project, I created a simple layout containing two Flexbox containers. The first container arranges elements horizontally, while the second container arranges elements vertically. Different Flexbox properties are used to control the alignment and positioning of the elements.

## Technology Used

* HTML

* CSS

* CSS Flexbox

## CSS Properties Used

* `height` – Sets the height of elements

* `width` – Sets the width of elements

* `background-color` – Sets the background color

* `border` – Adds a border around elements

* `border-radius` – Creates rounded corners

* `margin` – Adds space outside elements

* `padding` – Adds space inside elements

* `font-size` – Sets the text size

* `font-weight` – Controls the thickness of text

* `display: flex` – Creates a Flexbox container

* `flex-direction` – Defines the direction of flex items

* `justify-content` – Aligns items along the main axis

* `align-items` – Aligns items along the cross axis

## Project

The webpage contains:

* A main background container

* Two Flexbox containers

* Three boxes in the first Flexbox container

* Three boxes in the second Flexbox container

* Horizontally arranged elements

* Vertically arranged elements

* Different background colors for the boxes

* Center and end alignment using Flexbox properties

## Learning Goal

The goal of this project is to understand how **CSS Flexbox properties** such as `display`, `flex-direction`, `justify-content`, and `align-items` can be used to create and control different webpage layouts.
